1/día, bolsa de 60 = 2 meses). Mercado: mujeres argentinas (Caro).
Copy apto ANMAT: energía, metabolismo, menos ansiedad, bienestar. NADA de

---

## PARTE A — Setup técnico de Shopify (pasos)

1. **Crear tienda:** shopify.com → prueba gratis. Plan Basic alcanza para arrancar.
2. **Idioma/moneda:** Español (Argentina), ARS. Configurar en Settings → Markets.
3. **Tema:** empezá con **Dawn** (gratis) o un tema de conversión (Shrine, Impulse).
   Para una sola página de venta, Dawn + secciones alcanza.
4. **Apps recomendadas:**
   - **Judge.me** o **Loox** (reseñas con foto) → clave para la prueba social.
   - **Vitals** (todo en uno: reseñas, upsell, urgencia) si querés simplificar.
   - **Shopify Forms** o Klaviyo (captar mails).
5. **Pagos:** Mercado Pago + tarjetas. Settings → Payments.
6. **Envíos:** configurar CABA/GBA e Interior. Settings → Shipping.
7. **Dominio:** comprá tomanuva.com / nuva.com.ar.
8. **Páginas legales:** términos, privacidad, cambios/devoluciones (Shopify las
   autogenera en Settings → Policies).
